# 3.4 The Risk-Adaptive Decision Gate (RADG)

## 3.4.1 Mathematical Formulation of the RADG Decision Function

The core decision intelligence of the architecture is encapsulated in the **Risk-Adaptive Decision Gate (RADG)**. The RADG operates as a deterministic, piecewise decision function $D$ that evaluates two orthogonal, sequentially computed risk signals:
1. **Semantic Uncertainty ($U_{sem} \in [0, 1]$):** Quantifying linguistic ambiguity, missing parameters, and structural translation errors.
2. **Physical Transmission Viability ($\text{QoT}_{valid} \in \{0, 1\}$):** Quantifying physical feasibility via the analytical Gaussian Noise (GN) model.

The RADG maps the joint state space to an actionable operational space $\mathcal{A}$:

$$\mathcal{A} = \{ \text{approve}, \text{clarify}, \text{replan} \}$$

Formally, the decision function is defined as:

$$D\left(U_{sem}, \text{QoT}_{valid}\right) = \begin{cases} 
\text{clarify} & \text{if } U_{sem} > \tau_{sem} \\ 
\text{replan} & \text{if } U_{sem} \le \tau_{sem} \land \text{QoT}_{valid} = 0 \\ 
\text{approve} & \text{if } U_{sem} \le \tau_{sem} \land \text{QoT}_{valid} = 1 
\end{cases}$$

where $\tau_{sem} \in (0, 1)$ represents the operational semantic tolerance threshold (empirically calibrated to $\tau_{sem} = 0.30$).

---

## 3.4.2 Two-Layer Semantic Uncertainty Quantification ($U_{sem}$)

To guarantee robust intent parsing without false positives, $U_{sem}$ is computed through a two-layer hierarchical assessment:

### Layer 1: Structural CFG Validity ($v_{struct}$)

The generated PDDL constraint block $\mathcal{S}_{PDDL}$ is evaluated against the Context-Free Grammar $\mathcal{G}_{pddl}$ and verified against the extracted active node set $V_{sub}$:

$$v_{struct} = \begin{cases} 1 & \text{if } \mathcal{S}_{PDDL} \in \mathcal{L}(\mathcal{G}_{pddl}) \land \text{EndpointsExist}(\mathcal{S}_{PDDL}, V_{sub}) \\ 0 & \text{otherwise} \end{cases}$$

### Layer 2: Reverse Prompting Semantic Divergence ($d_{sem}$)

If $v_{struct} = 1$, the PDDL specification is reconstructed back into a natural language confirmation statement $\mathcal{I}_{recon}$ by an independent LLM prompt. The semantic divergence $d_{sem}$ is evaluated as the complementary agreement score:

$$d_{sem} = 1 - \text{Score}_{agreement}\left( \mathcal{I}_{NL}, \mathcal{I}_{recon} \right)$$

where $\text{Score}_{agreement} \in [0, 1]$ is computed either via cross-encoder semantic text similarity or structured LLM agreement classification.

### Composite $U_{sem}$ Evaluation

The composite uncertainty metric combines both layers into a fail-fast formulation:

$$U_{sem} = \begin{cases} 1.0 & \text{if } v_{struct} = 0 \text{ (Structural/Grammar Violation)} \\ d_{sem} & \text{if } v_{struct} = 1 \text{ (Syntactically Valid)} \end{cases}$$

Furthermore, if the human operator explicitly rejects an automated clarification during an interactive session ($\text{HITL}_{approved} = \text{False}$), the gate enforces $U_{sem} = 1.0$, preventing premature advancement to physical path calculation.

## 3.4.3 Deterministic Physical-Layer QoT Evaluation

Physical feasibility is assessed deterministically using the analytical coherent Gaussian Noise (GN) model for uncompensated optical fiber links.

### Optical Signal-to-Noise Ratio (Amplified Spontaneous Emission)

Along each fiber span $m$ of link $e_{ij}$, optical inline amplifiers (EDFAs) generate Amplified Spontaneous Emission (ASE) noise. The ASE noise power within optical reference bandwidth $B_{ref}$ is:

$$P_{ASE, m} = (G_m - 1) \cdot h \nu \cdot NF_m \cdot B_{ref}$$

where $h = 6.626 \times 10^{-34} \text{ J}\cdot\text{s}$ is Planck's constant, $\nu = 193.1 \text{ THz}$ is the optical carrier frequency, $G_m$ is the linear amplifier gain offsetting span attenuation ($\alpha \cdot L_m$), and $NF_m$ is the amplifier linear noise figure.

The linear Optical Signal-to-Noise Ratio due to ASE over link $e_{ij}$ with $M$ spans is:

$$\text{OSNR}_{ASE}^{-1}(e_{ij}) = \sum_{m=1}^M \frac{P_{ASE, m}}{P_{ch}}$$

where $P_{ch}$ denotes the launch channel power ($\text{W}$).

### Non-Linear Interference (NLI) Modeling

Under the coherent GN model, Non-Linear Interference (NLI) generated by Kerr non-linearities (Self-Phase Modulation and Cross-Phase Modulation) is modeled as an additive Gaussian noise source:

$$P_{NLI, m} \approx \frac{3 \gamma^2 P_{ch}^3 \cdot \ln\left( \pi^2 |\beta_2| B_{ch}^2 L_{eff} \right)}{2 \pi \alpha |\beta_2|}$$

where $\gamma$ is the fiber non-linear coefficient, $\beta_2 = -\frac{\lambda^2 D}{2\pi c}$ is the group velocity dispersion parameter, $B_{ch}$ is the channel symbol rate, and $L_{eff} = \frac{1 - e^{-2\alpha L_m}}{2\alpha}$ is the effective non-linear length.

The corresponding non-linear signal-to-noise ratio is:

$$\text{SNR}_{NLI}^{-1}(e_{ij}) = \sum_{m=1}^M \frac{P_{NLI, m}}{P_{ch}}$$

### Generalized SNR (GSNR) Accumulation

The total Generalized Signal-to-Noise Ratio for a candidate path $\pi = (e_1, e_2, \dots, e_H)$ composed of $H$ cascaded fiber links is computed by accumulating linear inverse SNR contributions:

$$\text{GSNR}(\pi)^{-1} = \sum_{h=1}^H \left( \text{OSNR}_{ASE}^{-1}(e_h) + \text{SNR}_{NLI}^{-1}(e_h) \right)$$

Converting to the logarithmic decibel scale:

$$\text{GSNR}_{dB}(\pi) = 10 \log_{10}\left( \frac{1}{\text{GSNR}(\pi)^{-1}} \right)$$

### Binary QoT Feasibility Indicator

The physical viability of the candidate path set $\mathcal{K}_{path}$ is evaluated against the design threshold $\text{GSNR}_{th}$:

$$\text{QoT}_{valid} = \begin{cases} 1 & \text{if } \exists \pi \in \mathcal{K}_{path} \text{ such that } \text{GSNR}_{dB}(\pi) \ge \text{GSNR}_{th} \land P_{rx}(\pi) \in [P_{rx,min}, P_{rx,max}] \\ 0 & \text{otherwise} \end{cases}$$

## 3.4.4 Decision Matrix and Action Execution Policies

The interaction between semantic and physical risk signals yields the complete RADG decision matrix:

| $U_{sem}$ Evaluation | $\text{QoT}_{valid}$ Status | RADG Decision | Pipeline Action & Human Engagement |
| :--- | :--- | :--- | :--- |
| **$U_{sem} > \tau_{sem}$** | *Not Evaluated* (Bypassed) | **`clarify`** | **Early HITL Clarification (Phase 3b):** Halts immediately before path search. Queries operator for missing endpoints or disambiguation. Loops back to Phase 2. |
| **$U_{sem} \le \tau_{sem}$** | $\text{QoT}_{valid} = 0$ (Infeasible) | **`replan`** | **Physical Risk HITL (Phase 6):** Path physics failed. Displays infeasible paths, achieved GSNR vs required threshold, and suggests constraint relaxation (e.g., lower GSNR target or alternate corridor). Loops to Phase 2 upon feedback. |
| **$U_{sem} \le \tau_{sem}$** | $\text{QoT}_{valid} = 1$ (Feasible) | **`approve`** | **Autonomous Auto-Approval (Phase 7):** Zero human friction. Compiles Planning Report and prepares configuration for testbed provisioning. |
